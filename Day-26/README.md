# Day 26 – Time Series Analysis & Forecasting

## 30-Day Data Analytics Cookbook

**Topic:** Understanding historical patterns and predicting future outcomes.

### Overview

Time Series Analysis examines data collected over time to identify trends, seasonality, and variations. Forecasting uses historical observations to estimate future values and support informed decisions.

### What You Will Learn

- Understanding time-series data
- Identifying trends and seasonality
- Preparing date-indexed datasets using Pandas
- Visualizing time-series patterns
- Calculating moving averages
- Building baseline forecasting models
- Evaluating forecasts using MAE and RMSE

### Practical Example

Using synthetic monthly citizen-grievance data, we analyze complaint patterns and demonstrate how forecasting can support resource planning in urban local bodies.

### Python Libraries

`pandas` | `numpy` | `matplotlib` | `scikit-learn`

### Run the Notebook

```bash
pip install pandas numpy matplotlib scikit-learn jupyter
jupyter notebook
```

Open `Day_26_Time_Series_Analysis_Forecasting.ipynb` and execute the cells sequentially.

### Key Takeaway

Forecasting is not simply predicting numbers. It helps organizations anticipate demand, allocate resources, and make proactive decisions.

**Data analytics is not about dashboards. It is about decisions.**
