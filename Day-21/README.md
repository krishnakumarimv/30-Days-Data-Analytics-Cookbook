# Day 21 – Correlation & Regression

## From “What Is Related?” to “Can We Predict?”

Correlation helps us understand relationships between variables, while regression helps quantify those relationships and use them for prediction.

### Key Concepts

- Pearson Correlation
- Correlation vs Causation
- Simple Linear Regression
- Slope and Intercept
- R²
- MAE and RMSE
- Residual Analysis
- Multiple Regression
- Regression Assumptions

### Practical Example

This notebook uses a synthetic public grievance dataset to examine the relationship between:

- Monthly complaint volume
- Average resolution time

The analysis demonstrates how statistical relationships can support workload analysis and resolution-time prediction.

### Notebook Workflow

1. Create the dataset
2. Explore the relationship
3. Calculate Pearson correlation
4. Build a linear regression model
5. Interpret the regression equation
6. Evaluate the model
7. Analyze residuals
8. Generate a prediction
9. Explore multiple regression concepts

- NumPy
- Pandas

### Public Governance Applications

Correlation and regression can support:

- Complaint workload analysis
- Resolution-time prediction
- Demand forecasting
- Resource allocation
- Service-level monitoring
- Ward and zone performance analysis
- Early-warning systems

### Key Takeaway

**Correlation asks:**  
What variables move together?

**Regression asks:**  
Can we quantify the relationship and use it for prediction?

**Data → Relationship → Model → Prediction → Decision**
